Komponenten herunterladen

Die originalen React-Komponenten aus diesem Repository. Tailwind CSS und lucide-react werden vom Popup benötigt.

Banner Popup Beide (ZIP)
„Beide (ZIP)“ lädt das komplette Repository herunter. Die einzelnen Buttons laden nur die jeweilige JSX-Datei.

In deine React-Website einbauen

Code kopieren, Dateien hinzufügen und beide Komponenten einbinden.

Beispiel: App.jsx
import KdsBanner from "./KdsBanner";
import KdsPopup from "./KdsPopup";

export default function App() {
  return (
    <>
      {/* Deine normale Website */}
      

        {/* ... dein Inhalt ... */}
      


      {/* KDS Banner – dort platzieren, wo es erscheinen soll */}
      

      {/* KDS Popup – einmal global einbinden */}
      
    </>
  );
}
01 — DateienKdsBanner.jsx und KdsPopup.jsx herunterladen und in dein React-Projekt legen.
02 — AbhängigkeitenTailwind CSS und lucide-react müssen in deinem Projekt eingerichtet sein.
03 — EinfügenDie beiden Imports und Komponenten wie im Beispiel in deine App bzw. dein Layout übernehmen.
Der Code ist für eine React-Website gedacht. Bei einer normalen HTML/CSS/JS-Website funktioniert dieser React-Code nicht direkt.
